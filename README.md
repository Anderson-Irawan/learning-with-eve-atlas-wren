# Learning with Eve, Atlas & Wren

A seven-slide, editable presentation about recent Alicorn project work. It separates research-informed proposals from results: the Alicorn evaluation has not been run.

## View
Open the GitHub Pages site once deployment is enabled.

## Edit
- Select **Edit copy** in the deck to change text in your current browser. Those edits are saved only in that browser's local storage.
- To make a permanent update for everyone, edit the copy in `index.html`, then commit and push the change to this repository.

Navigation: arrow keys or buttons. Press **E** to toggle copy editing and **F** for fullscreen.
